# Xilften API

API REST para gerenciamento de catálogo de filmes e serviços de streaming, desenvolvida com **Spring Boot** e arquitetura moderna.

## Sobre o Projeto

A **Xilften API** é uma plataforma backend que permite aos usuários descobrir filmes disponíveis em diferentes serviços de streaming.

O projeto foi desenvolvido com foco em:

### Organização de Conteúdo
Categorização eficiente de filmes e relacionamento entre entidades como filmes, categorias e serviços de streaming.

### Múltiplos Serviços
Integração com diferentes serviços de streaming para facilitar a descoberta de conteúdos disponíveis.

### Segurança
Autenticação e autorização utilizando **Spring Security** e **JWT (JSON Web Token)** para proteção dos endpoints.

### Performance
Queries otimizadas utilizando **Spring Data JPA** e estrutura preparada para uso de cache.

### Escalabilidade
Arquitetura em camadas (**Controller, Service, Repository**) preparada para evolução e crescimento da aplicação.

## Tecnologias Utilizadas

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL
- Maven
- Git
